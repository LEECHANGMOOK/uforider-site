BlueprintLibrary

BlueprintLibrary is a free Windows desktop application for saving, previewing, and reusing Unreal Engine Blueprint presets.

Features

  • Save Blueprint node presets locally
  • Preview Blueprint graphs
  • Copy presets back to Unreal Engine
  • Import and export .bpl preset files
  • Synchronize Blueprint presets using Google Drive

Google Drive Access

Google Drive access is used only to synchronize BlueprintLibrary preset files between the user's devices.
